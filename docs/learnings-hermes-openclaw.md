### 1.1 The plagiarism rule (binding)

1. **Mechanisms are ideas; ideas are taken with attribution.** We describe *what a mechanism does and why*, then implement it independently in TypeScript. No Hermes Python or OpenClaw TypeScript is copied, translated line-by-line, or vendored.
2. **No product identity.** We do not reuse Hermes/OpenClaw naming vocabulary as our own: no `SOUL.md`, `MEMORY.md`/`USER.md` as *our* format names, no `HERMES_HOME`, no `~/.hermes` layout mimicry, no Hermes config-key names, no `memory-core` phase constants, no `__openclaw_memory_core_*` sentinels. Hermes's own dossier flags exactly this boundary — these names are "Nous Research/Hermes-specific product identity, not just technical mechanism" (`RN-hermes §"What our harness must explicitly NOT copy"` item 10). We read and write those files where *interoperability* requires it (import, and the PLUR1BUS↔OpenClaw adapter), and we name our own artifacts ourselves.
3. **UI: tokens only, with attribution.** OpenClaw is MIT (`OC:LICENSE`, "Copyright (c) 2026 OpenClaw Foundation"). The Control-UI/Carapace bridge carries its own attribution header, which any adaptation must reproduce verbatim — opened and confirmed at `OC:ui/src/styles/carapace-control-ui.css:1-23`:

   > `/* Adapted from openclaw/carapace at 6c38d2a9b558104957d581033bce5a127632d60e.`
   > ` * MIT License, Copyright (c) 2026 openclaw.`
   > ` * Permission is hereby granted, free of charge, to any person obtaining a copy` … [standard MIT grant and no-warranty clause] …
   > ` * Control UI owns theme selection; Carapace owns the semantic component roles.`
   > ` * Keeping this bridge pointed at the resolved Control UI tokens makes every`
   > ` * shipped theme family, mode, and imported custom theme work without a`
   > ` * Carapace-side copy of the product theme catalog. */`

   We adapt the **design tokens** (colour/radius/spacing/typography values and the `--oc-*` semantic bridge idea) under that header, with an added "Adapted from openclaw/openclaw @ b9421f4" line and our own token namespace. We do **not** copy component markup, page layouts, copywriting, icons or the OpenClaw word mark. Full token inventory: `RN-openclaw §3`.
4. **Attribution lives in the repo**, not only in a commit message: `THIRD-PARTY-NOTICES.md` names Hermes (MIT), OpenClaw (MIT), and each borrowed mechanism with its upstream reference.
5. **Third-party reverse-engineering is marked as such.** Claude Code's internal compaction constants (`effective_window − 13,000`, OpenCode's 20k/40k guards) come from a teardown blog, not a vendor doc — cite as **[secondary]**, never as contract (`RN-sota §2`, Justin3go 2026-04-09).

**Conclusion — what a reliable three-phase scheduler needs (feeds ADR-009).** Nine requirements, each traceable to a named failure:

1. **Per-phase status record**: `enabled`, schedule, timezone, `lastRunAt`, `nextRunAt`, `durationMs`, `outcome`, `reason`, counts — written **before any early return**, so "skipped because X" is as visible as "completed". *Fixes:* PLUR1BUS's four-of-six silent skips and OpenClaw #62857-class silent init failures.
2. **Outcome counters** per run (candidates considered / shortlisted / promoted / rejected-by-gate / deduped) surfaced in the UI and by a doctor command. *Fixes:* "it ran but nothing happened" being indistinguishable from "it never ran".
3. **Circuit breaker + rate limit + hard spend cap** per cycle, aborting the cycle on breach. *Fixes:* #65550 (94 runs / 65 min / $4.35).
4. **Content-hash dedupe on candidates**, so the same material cannot be reprocessed in a tight loop. *Fixes:* #65550 root cause (1).
5. **Staleness eligibility**: candidates past `maxAgeDays` or with zero demonstrated utility are ineligible, and the recall counter must cover every path that can be promoted. *Fixes:* #142393's inverted incentive and #65550 root cause (3).
6. **Importance-accumulation trigger** (Generative Agents) with cron as a floor, not the only path. *Removes:* the whole "3 a.m. job chewed stale candidates" class.
7. **Guaranteed dream diary**: the diary write is part of the run's success criterion, not fail-open. A run whose narrative is empty stays **open** (PLUR1BUS already fixed this in 7.12.58) and is retried; it is never marked `completed`. *Fixes:* #143206 and the observed "completed with no dream ever written".
8. **Own scheduler, never host cron** (D4), with declarative per-agent staggering and an explicit `singleton` flag — PLUR1BUS today hand-tunes stagger offsets in comments and declares concurrency only on `gc-run`.
9. **No silent truncation anywhere in the pipeline**: over-budget promotion emits a visible warning and a deferral record. *Fixes:* #142393.

Two further notes for ADR-009: OpenClaw's consolidation of three cron jobs into one reduces the "N jobs drift apart" class but **concentrates all three phases on a single trigger path** — if the one event never fires, no phase runs, which matches the observed issue pattern (#62920, #62296, #62857 are all *trigger* failures). And nobody publishes a quality measurement for dreaming: OpenClaw documents the mechanism in unusual detail and measures nothing. The quantified evidence we do have is Generative Agents' reflection ablation and Letta's sleep-time compute — so ADR-009 must define a measurable outcome before the feature is called done.

## 3. "Better than OpenClaw and Hermes" — operational acceptance criteria

Reviewed from `RN-sota §7`. Criteria 1–14 are carried over; **sharpenings are marked**. Each is testable.

| # | Criterion | Failure it prevents | Source |
|---|---|---|---|
| 1 | **Compaction can never deadlock.** Summarisation runs over a bounded slice, sized so the summariser prompt is provably under the window regardless of session size. *Sharpened:* the bound is asserted by a property test over synthetic sessions from 1 to 10× the window | OpenClaw #20760 (`prompt is too long: 202350 > 200000`, closed as not planned), #25620 | `RN-sota §7` |
| 2 | **A single tool result can never exceed the budget.** Truncate-with-pointer at the tool boundary; the full result is stored in the memory engine and a handle is returned | "read one huge file and the session is dead" | `RN-sota §7` |
| 3 | **No silent truncation, ever.** A clipped injection emits a visible warning plus a deferral record. *Sharpened:* applies to all three sites — prompt injection, memory promotion, and subagent returns — and the warning is a typed event, not a log line | OpenClaw #142393 (MEMORY.md at 9,728 bytes vs a 9,000-char cap, tail silently dropped) | `RN-sota §7` |
| 4 | **Consolidation has dedupe, a circuit breaker and a spend cap.** Content-hash dedupe on candidates, max runs per hour, hard per-cycle token/dollar cap that aborts the cycle | OpenClaw #65550 (94 sessions / 65 min / $4.35 / 100% zero-confidence output) | `RN-sota §7` |
| 5 | **Promotion requires demonstrated utility.** Never promote `recalls = 0`, and the recall counter must cover every path that can be promoted | #142393's inverted incentive (dreaming paths excluded from recall tallying) — a pure design error, encoded as a test | `RN-sota §7` |
| 6 | **Consolidation is importance-triggered, not cron-triggered**, with cron only as a floor | The "3 a.m. job chewed stale candidates" class | `RN-sota §7`; Park et al. arXiv 2304.03442 |
| 7 | **Memory is live within a session without breaking the cache.** Frozen snapshot in the cached zone (T3) + mid-session recall as `tool_result` in the uncached tail | Hermes's frozen-memory trade-off: the agent cannot act on what it just learned | `RN-sota §7`, §2.3 above |
| 8 | **Budget and cost are first-class.** Per-session and per-subagent token/dollar budgets, enforced, with visible accounting. *Sharpened:* also per-agent, per-project and per-user (brief §7), checked **before** every model call, subagent spawn and consult | Hermes's documented total absence of cost governance; OpenClaw #65550's unnoticed spend | `RN-sota §7`; brief §7 |
| 9 | **Model switching does not cost a full re-read.** Per-model cached prefixes, or warn-and-confirm before an invalidating switch | Hermes FAQ: "the cache key includes the model" | `RN-sota §7` |
| 10 | **Verification is structural, not self-reported.** External verifiers (typecheck/test/lint gates, features-default-to-failing lists) decide success | The #1 Hermes user complaint: the agent reports success on failed tasks **[secondary]** | `RN-sota §7`; Anthropic "judge end states" |
| 11 | **Self-improvement never overwrites human-authored artifacts,** and mined skills are inactive until reviewed. *Sharpened:* the equivalent of Hermes's `write_approval` is **on by default** for self-knowledge, off for world-facts | Hermes complaints #2 and #9 (overwritten customisations; erroneous generated skills) **[secondary]** | `RN-sota §7`, §6 |
| 12 | **Environment discovery is continuous, not a startup snapshot** — or at minimum re-probed in the background with a cache. *Sharpened:* and never on the prompt-build path (§2.12) | Hermes's one-shot `bash -l` capture and the macOS launchd minimal-PATH class of bugs | `RN-sota §7`, §4 |
| 13 | **Subagents are fully observable** — every subagent is a real, replayable session in the memory engine | pi's "black box within a black box" objection, unaddressed by both systems | `RN-sota §7`, §5 |

## 4. Top design rules for the harness (ranked)

Adapted from `RN-sota §"Top 15 design rules"`, re-ranked for this project's constraints (D1–D11) and extended where PLUR1BUS-specific evidence changes the priority. Feeds ADR-001, ADR-003 and ADR-010.

| # | Rule | Source |
|---|---|---|
| 1 | **Two-zone prompt: everything stable before anything volatile; nothing time-varying above the last breakpoint.** Map onto Anthropic's four cache tiers; frozen memory snapshot in T3, never T2. Serialise tool schemas with sorted keys and test zone-hash stability in CI | Writer arXiv 2607.06906; Anthropic prompt caching — `RN-sota §3` |
| 2 | **Build the core as a resident async submit/event engine with thin clients** (CLI, TUI, daemon, HTTP API, tests all consume the same typed event stream). Expensive to retrofit, free to start with | codex-rs 2026-03-28; claude-agent-sdk-typescript#33 (~75% of cold-start wall-clock is reusable overhead) — `RN-sota §1,§4` |
| 3 | **No network call and no subprocess spawn on the prompt-build path.** Capabilities from cache with background refresh; pre-load local models; use the typing window. Target D6's numbers, benchmarked from M1 | Hermes PR #59332 (measured ~4.3s → ~0.9s submit-to-dispatch) — `RN-sota §4`; brief D6 |
| 4 | **Memory is live in-session without breaking the prefix**: frozen snapshot in the cached zone, mid-session recall as `tool_result` in the tail, injection under a global char budget with droppable/non-droppable blocks | `RN-sota §2`; `P1B:index.js:13315-13325`; `P1B:lib/inject-budget.js:9-20` |
| 5 | **Layer compaction cheapest-first** (trim tool results → protect the cache prefix → LLM summary last), **hide rather than delete**, and make the summariser slice provably bounded so compaction can never deadlock | Justin3go 2026-04-09 **[secondary]**; openclaw#20760 — `RN-sota §2,§7` |
| 6 | **One declarative `ProviderProfile` per provider, one `WireAdapter` per wire shape**, selected once. | 12 | **Consolidation discipline**: staged phases, importance-accumulation trigger with cron as a floor, explicit scoring weights, all-gates-must-pass promotion, the model emits typed operations a deterministic validator applies, bounded prior-entry loss, fresh contexts, an auditable diary — **plus dedupe, a circuit breaker, a spend cap, and a run ledger written before any early return** | Park et al. arXiv 2304.03442; OpenClaw dreaming docs; openclaw#65550, #142393; `RN-crons §1` |

| 14 | **Budgets and provenance are enforced, not advisory**: per-agent/project/user token and dollar budgets checked before every call; every memory record carries provenance and promotion gates on it; content from channels, files, tools and other agents is **data, not instructions** | Writer arXiv 2607.06906; OpenClaw provenance exclusion — `RN-sota §3,§5`; brief §7, auftrag §11 |

Ship-first discipline still applies: build the loop and the cache discipline first; add consolidation, skill mining and fan-out when a real failure demands them (HumanLayer, `RN-sota §6`).
