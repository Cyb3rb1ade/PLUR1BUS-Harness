# Inbox

The Inbox (`#/inbox`) lists what the harness wants you to see: approvals waiting for you, failed jobs, media indexing, pairings and channels that need attention, and break-glass notices about your own data. Only metadata is shown. The German version of this page is [../de/posteingang.md](../de/posteingang.md).

## Reading entries

- Each entry has a kind (for example *Approval*, *Failed job*, *Pairing*, *Channel*), a severity (*Info*, *Warning*, *Critical*) and a status (*Unread* or *Read*).
- Use **Kinds** to show one kind only, or **All kinds** for everything.
- Turn on **Only unread** to hide entries you have already read.
- **Load more** loads the next page. If the list changed while you were paging, it reloads from the top and says so.

## Acting on an entry

- **Open** goes to the page the entry is about (for example the approval or the channel).
- **Mark as read** changes the status of that one entry.
- **Mark all as read** marks every unread entry as read.
- **Dismiss** hides the entry from your Inbox.

## When nothing shows up

- An empty list means no entry matches the current filter. Change the filter, or wait: new things appear here as they happen.
- If the Inbox cannot be loaded, the page shows an error with a retry button.
