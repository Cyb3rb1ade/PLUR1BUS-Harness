# M5 collaboration demo

The five-phase PR stack depends on M3 P1 (#493). Fan-out remains disabled by
default. Do not enable it merely because deterministic fixtures pass.
The owner-approved Web allowlist is included in #520. Real HTTP/Core acceptance
is in `collab/web-transport.test.ts`; mocked-browser checks separately cover UI.
M3 P1 remains an open dependency, and no production deployment is claimed.

## Reproduce local evidence

Use Node 24.21 and pnpm 10.28.0 (on this Mac, Node is in `$HOME/.node24/bin`).

```sh
pnpm gen
pnpm run eval:m5
node --conditions=source scripts/m5-fanout-eval.mjs --check
node --experimental-strip-types --conditions=source --no-warnings=ExperimentalWarning --test --test-concurrency=1 packages/core/test/collab/*.test.ts
PLUR1BUS_WEB_E2E_REQUIRED=1 node --experimental-strip-types --conditions=source --no-warnings=ExperimentalWarning --test --test-concurrency=1 packages/web/test/chat-promotion.test.ts packages/web/test/handoff-card-browser.test.ts
```

The eval has 24 fixtures per mode with the same 8,192-token hard project budget:
single 24/24, 576 settled tokens/24 calls; peer 24/24, 1,728 tokens/72 calls.
This demonstrates routing, provenance and equal-budget accounting; it establishes
no live-model quality advantage.

## Collaboration and replay

1. Run `collab/tools.test.ts`: the fake provider emits a real consult tool call,
   the peer answers through the production provider/dispatcher seam, and the
   caller consumes only a provenance-tagged tool result. The cycle/depth/pair/
   fan-out limits remain active.
2. In Projects, expand a trace. Inspect its duration, tokens, known/unknown cost
   and delegation tree. Focus the transcript link and press Enter. Replay reads
   persisted redacted events without calling a model.
3. Use the replay test's second person to verify denial, and its reopen test to
   verify the identical transcript. Legacy traces have no invented transcript.
4. D104 tests reject forged/foreign/expired/consumed references, oversized handoff,
   invalid schemas after one repair, ack bypass and repair that changes authority.
5. Timeout/user-abort tests retain a partial result in the card and trace.

## Coding completion

1. `collab/coding-gate.test.ts` creates a fixture Git repo with committed verifier
   conventions. Its delegate claims green while the test exits red: completion
   is refused and the card stays in its column.
2. The same fixture requires an independent exact-tree reviewer at 200 lines;
   later edits invalidate that pass. Missing tools/sandbox refuse completion.
3. Its network and private-store probes are denied in the real macOS sandbox;
   its hanging process is timed out. Python/Rust/Go/Gradle command detection is
   covered separately from a live runtime installation.
4. A human lead/Owner/Admin can call the human-only `task.complete` RPC with a
   nonempty `overrideNote`. The agent tool accepts no override argument. Inspect
   the audit record. Do not treat the delegate's report as verifier evidence.

## Private chat promotion

1. Open your own Direct Chat. From Chat actions choose **Promote or link chat**.
2. Choose an existing project. Leave **No content**, preview, and confirm. No
   chat message/title/id appears on the project board; the chat stays private.
3. Repeat with selected messages. Select one harmless message, preview the exact
   text, then confirm. Only that selection becomes a project card. Changing any
   choice clears the confirmation-ready preview.
4. Try a written summary, a new card and a new project. Nothing is inferred from
   the private chat title. Incognito preview content remains in RAM until the
   explicit publish action.
5. A second person, including another Owner, cannot preview or confirm the first
   person's chat. Expired/stale previews and foreign message IDs are rejected.

Owner defaults retained: external targets stateless; depth one; 3 starts per
turn/2 per pair; 25 model rounds/5 minutes; budget before fan-out; abort propagation;
fan-out off. Optional Buzz/Matrix mirroring and live/nightly eval are not enabled.
