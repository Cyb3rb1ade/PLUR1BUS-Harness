# D106 phase 2 handoff — sandbox wiring and central taint (Draft)

Builds on #523 and #508 (grok/d109-followups 7ff5f60c, merged normally). No decide()/begin() signature changed.

## Inventory and decisions

Production composition uses sandbox process/host adapters. required=true is the schema default; missing helper refuses spawn. `tools.sandbox.required=false` is owner-only (`x-write-roles`) and audited by configuration and before **each** bypassed launch; exec results carry sandboxed=false. Doctor adds NOT SANDBOXED warning, visible through the existing Doctor report UI. Config metadata regenerates the generic settings search index.

Outside-root exec cwd is classified canonically and included in the dispatcher action. After its authorization, only that invocation receives an extra root; the configured roots never change. Credential deny paths, config.json, runtime and helper binaries remain denied. Fixed trusted system executable lookup ignores requested PATH. Existing #508 live cwd/env fingerprint checks and once-consumption are preserved.

Central dispatcher result handling records taint for web.*, mcp.*, peer.*, untrusted tools and fs.read outside roots. The record is keyed by principal/agent/session/turn and cannot be cleared by a policy-context hook. It conservatively sets readPrivate=true; the **existing** evaluator then suspends standing taint-sensitive/external grants, still permitting valid once grants. This does not widen the evaluator to unrelated local grants. Peer results arriving outside this tool-result path remain a gap.

## Behaviour changes

Host subprocesses now fail closed where isolation cannot support OS services. Hostctl process/native/search/trash routes are explicitly refused under required=true until its separate worker protocol supports sandbox policy; required=false is audited before delegation. No unsandboxed fallback. Clipboard stdin adapter is missing and refused. This is intentionally a Draft: it is not full host parity.

## Validation

Existing composition temp fixture now canonicalises macOS /var alias before testing canonical results (assertions unchanged). No CI polling or GitHub merge.
