# M2 phase 3 — voice broker RPC

Status: **partial, draft; no live acceptance**. Independent base `4557176c`.

## Inventory and decisions

Add closed-schema `voice.session.create` for both OpenAI voice providers, additive human-only RPC_RULES with `agent.use`, trusted connection surface check, explicit parent kind/region/billing/terms, credential-free projected result and `voice.session.created` audit. Tiny core registration; logic in `rpc/voice-session-surface.ts`. The existing VoiceBroker owns reservations, sideband, usage, expiry and shutdown. Re-check parent metadata on every credential lease; a changed billing route cannot reuse another request. Audit/cancellation failure after creation closes the session. DE/EN setup: `docs/voice-sessions.md`.
