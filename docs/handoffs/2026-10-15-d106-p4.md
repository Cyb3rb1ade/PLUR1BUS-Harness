Builds on #526 after refreshing origin/main. Stack prerequisites remain Draft.

## Inventory and decisions

`catalog/host-eval-scenarios.json`: 20 named scenarios, independent transcripts/oracles, explicit application/path/content targets. `host-eval.ts` executes real dispatcher policy and scratch file operations through a safe test rig; process/OS-service ports are fake, even in live model mode. Model responses see prompts and tool definitions, not expected calls. Outcomes, exact tool/arguments, scratch write/read and JSON process result are checked. Tool wire names use the same dot→underscore aliases as production.

`scripts/eval/tool-eval-host.ts`: deterministic PR replay or credential-gated nightly Chat Completions adapter. No paid/live model was called locally. The local HTTP integration test drives the entire adapter over 20 responses without external network or desktop actions. Missing model credentials produce skipped per-model records. Completed nightly runs under .95 or with policy escapes fail. Reports include explicit evidence fake/recorded/live and per-model files, plus host-reports.json and gate.json.

`host-eval-store.ts`: bounded input, seven-day freshness, corpus content hash, complete unique scenario ids, count/rate/escape consistency; bad/missing/skipped/fake evidence is unknown, never supported. Exact 19/20 passes; 18/20 is limited. A policy escape limits any score. Required models are checked individually, never averaged; duplicates/missing evidence block.

The required **release** inventory is independent `catalog/host-eval-defaults.json`, currently empty because no authoritative shipped chat-default inventory was found on this base (`modelProfiles` defaults to {}). Selecting models through PLUR1BUS_HOST_EVAL_MODELS cannot narrow release coverage. `--require-release` remains blocked until owner-reviewed inventory + recorded/live evidence exist. Doctor's runtime default coverage reads configured default candidates; synthesized provider defaults still need an authoritative source.

Models.list adds schema-defined optional toolUse, generated through pnpm gen; Models page and Doctor display supported/limited/unknown, with DE/EN copy and browser tests. No new RPC error code. User docs and bundled Help pages explain limitations. Milestones preserve M8 acceptance 8 as open and D106 as partial.
