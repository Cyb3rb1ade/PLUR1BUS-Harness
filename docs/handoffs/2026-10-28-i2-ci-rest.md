- The complete API package suite reports 878 tests: 872 passed, 0 failed, 3 existing skips and 3 existing TODOs.
  The helper/OpenAPI subset passes 18 tests. The two diagnostic regressions first failed against the old helper.

  11,684 ms; create the depth-20 tree 5 ms; list to depth 16 769 ms. This identifies the local listing cost;
  it does not attribute the Windows timeout. The focused command intentionally selects one existing test.

  Core and debug CLI. These are not release-binary or hosted performance results.

  a_home_with_spaces_and_umlauts_works_for_create_list_and_remove`: 1 passed, 7 filtered out on Linux,
  using this worktree's own compiled CLI. The Windows branch remains unverified locally.
- The unchanged Core B2 backlog/stop test passes on Linux. Its suite time includes the deliberate six-second
  wait for the delayed capture; that duration is not the time spent in `stop()`.

  runtime and the flat embedder. It exercises daemon restart, chat, backup/verify/restore and clean stop;
  it does not reproduce or explain the historical Windows failure.
