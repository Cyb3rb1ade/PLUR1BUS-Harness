## `plur1bus`

PLUR1BUS harness — self-hosted multi-agent memory harness

**Usage:** `plur1bus [OPTIONS] <COMMAND>`

###### **Subcommands:**

* `setup` — Install the harness (runtime, service registration) — 2a-H3
* `1staid` — Check and repair the installation — 2a-H3
* `agent` — Agents (personas): list, create, remove, status
* `memory` — Memory: add and recall through the core
* `dreams` — Dreaming jobs: status, run, log
* `config` — Configuration: get, set, schema
* `module` — Modules — 2a-H3
* `daemon` — Supervisor control — 2a-H3
* `service` — OS service registration — 2a-H3
* `core` — Core process (internal)
* `update` — Update check — 2a-H3
* `user` — Users — M2
* `model` — Models and provider profiles — M2
* `login` — Provider login (API keys, OAuth) — M2
* `channel` — Channels — M4
* `project` — Projects — M3
* `import` — Import from OpenClaw/Hermes — M1b-3
* `uninstall` — Uninstall — M8

###### **Options:**

* `--home <PATH>` — State root (default: ~/.plur1bus, %LOCALAPPDATA%\PLUR1BUS, or $PLUR1BUS_HOME)
* `--json` — Machine-readable output (stable shape, see docs/cli.md)

[experimental] List captured memory entries

**Usage:** `plur1bus memory list [OPTIONS] --agent <AGENT>`

###### **Options:**

* `--agent <AGENT>`
* `--topic <TOPIC>` — filter by topic (mutually exclusive with --since/--until)
