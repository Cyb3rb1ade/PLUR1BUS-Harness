## Measurement and gates

`scripts/bench/startup.mjs` retains every sample and uses nearest-rank percentiles. “Cold” means a fresh process/home, **not flushed OS/antivirus caches**; flushing requires privileged, disruptive operations and is not attempted. Healthy readiness requires an authenticated `core.status` reporting `process.state=ready`, `engine.ready=true`, and `engine.degraded=null`. Socket readiness is reported separately. Model warming is never replaced by the flat seam in the real-model scenario.

New job `perf-startup` in `ci.yml` builds and measures on macos-15, windows-2025, windows-11-arm, ubuntu-24.04 and ubuntu-24.04-arm. Each job writes JSON, Markdown and a summary for both the flat and real-model scenarios. Timings are advisory; malformed/missing measurements fail the job. Existing jobs and their B1/B6/B11 gates remain unchanged. B9's existing proxy test remains unchanged.

No new timing gate is promoted: **KNOWN-GAP P1-GATE: three consecutive green runner series and a separate, justified promotion commit are still required.** No CI was polled. Windows x64/arm64 and Linux x64/arm64 measurements are **not available from this local macOS session**; their artifact paths are `startup-<target>/startup-{benchmark,models}.{json,md}`. macOS CI is also pending, distinct from the local macOS measurement.

`help-isolation.test.ts` proves top-level and subcommand help succeed with invalid configuration, create no home files, and succeed when the home is a regular file. Source inspection places clap help exit before home resolution. This is a behavioral test, **not a kernel file-access/syscall counter**. KNOWN-GAP P1-WIN: Windows process/AV/file-access tracing and any resulting repair require actual Windows evidence; no Windows cause or speedup is asserted here.
