# C2: Gemini adapter (Google Generative Language API)

**Goal.** `packages/providers/src/gemini/**`: a native adapter for `generateContent` / `streamGenerateContent`
(AI Studio, `https://generativelanguage.googleapis.com/v1beta`), behind the same call surface as the
`chat_completions` adapter (`complete`, `stream`, same `ChatRequest` / `ChatResult` / `ChatStreamEvent`, same
`ProviderError`). Source: `docs/provider-matrix.md` row "Google AI / Gemini API (AI Studio)".

**Files.** New: `packages/providers/src/gemini/{types,request,response,errors,credentials,client,index}.ts`,
`packages/providers/test/gemini/*.test.ts` + a fake-server helper. Touched (minimal): `src/client.ts` (only `export`
on the existing `Run`, `chunks`, `readText` and the default constants; no behaviour change), `src/index.ts` (one
export line), `README.md` (one section). `docs/provider-matrix.md` is not changed.

## Tasks
1. Request mapping (`request.ts`): system/developer -> `systemInstruction`, user parts (text, `data:` images ->
   `inlineData`), assistant -> role `model` with `functionCall`, tool results -> grouped `functionResponse`, tools ->
   `functionDeclarations` (`parametersJsonSchema`), `toolConfig`, `generationConfig`; fixed key order.
2. Response mapping (`response.ts`): one accumulator for both paths (chunk = full `GenerateContentResponse`), text,
   thought parts -> reasoning, whole `functionCall` parts -> tool-call events, `usageMetadata` -> `Usage`.
3. Typed errors (`errors.ts`): `GeminiSafetyBlockError` (prompt block and candidate block), HTTP/in-stream
   classification incl. `RetryInfo.retryDelay`, invalid-key-as-400, token-limit-as-400.
4. Auth (`credentials.ts`, `client.ts`): key read per call from a `SecretReader` port (structurally the core
   `SecretStore`), sent only as `x-goog-api-key`; never URL, query, body, error text.
5. Tests against a loopback fake server (no network): stream, non-stream, tool roundtrip, blocks, 429, leak marker.

## Acceptance -> test
| Acceptance | Test |
|---|---|
| streamGenerateContent streams text/reasoning/usage | `test/gemini/stream.test.ts` |
| generateContent gives the same result as the stream | `test/gemini/complete.test.ts` |
| systemInstruction | `test/gemini/request.test.ts` |
| tool call roundtrip (functionDeclarations, functionCall, functionResponse) | `test/gemini/tools.test.ts` |
| safety block is a typed error (prompt and candidate, stream and non-stream) | `test/gemini/safety.test.ts` |
| tokens from usageMetadata | `test/gemini/stream.test.ts`, `complete.test.ts` |
| key only via secret store, in the header | `test/gemini/auth.test.ts` |
| 429 incl. retry delay | `test/gemini/errors.test.ts` |
| secret never leaks (URL, body, errors, results) | `test/gemini/leak.test.ts` |
