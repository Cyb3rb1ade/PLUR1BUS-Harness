# D4: log query RPC (`logs.query`, `logs.tail`)

Branch `claude/d4-logs-rpc`. Spec: `docs/superpowers/specs/2026-10-01-logging-and-diagnostics-design.md` (D111 §2.1, §2.2, §4, §7).
Code: `packages/core/src/logs/**`. Reads the protected files under `<home>/logs/`; writes nothing.

## Design

* **Sources.** Diagnostic stream: `logs/<role>.log` plus rotated `<role>.log.<n>` (`.1` newest, S17 rotation of
  `module-api` `createLogger`). Audit stream: `logs/audit.log` (+ rotated copies if any). `*.out.log` is wrapped child
  output and is a diagnostic component `<role>.out`. `payload.log` is never read (opt-in, short-lived, §2.5).
* **Streaming.** Files are read through an fd in 64 KiB chunks. Forward and backward line iterators, a binary search by
  `ts` inside a file (`seek.ts`), and a k-way merge over files. Memory is bounded by chunk size, line cap and `limit`.
* **Half and corrupt lines.** An unterminated last line is ignored; a line that is not a JSON object with a valid `ts`
  and (diagnostic) `level` is counted in `corrupt`, never fatal. A line over the cap is skipped and counted.
* **Rotation.** All candidate files are opened first and checked against their path identity (retry up to 3 times); a
  rotation during the scan cannot make an fd read the wrong file. A rotation between two `logs.tail` polls changes no
  record's position: the cursor is `(ts, hash-of-line)`, not a file name or offset.
* **Cursor.** Opaque base64url of `{v, ts, h, fp}` (`fp` = fingerprint of filters+order). Another filter set is
  `E_INVALID_PARAMS reason=cursor-mismatch`.
* **Redaction.** Output goes through a reader-side redactor built from `log-schema/schema/redaction.json` (key, pattern,
  url, path rules; pii only when `logs.redactPii`). The text search runs on the *redacted* text, so a query cannot be
  used as an oracle for a secret.
* **`logs.tail`.** Request/response long poll (`waitMs`, abortable by the connection and the core's stop): first call
  returns the last `limit` matches, later calls the records after the cursor. RBAC is per call.
* **RBAC.** New action `logs.query` (Owner/Admin), both methods; audit stream included.
