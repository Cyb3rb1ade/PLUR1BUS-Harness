# Provider prompt caching and token counting — reference values (2026-10-25)

Research record for plan §2.6 and [RE-14](RE-14-token-counter.md). Each row was researched from vendor documentation and checked by an independent second pass; corrections from that pass are applied. These values seed `packages/providers/schema/cache-profiles.json` (RE-D21) and are not maintained here: once the table exists, it is the source, and this file stays as the dated record. Vendors change these contracts often (plan RE-R11); re-verify a row before relying on it.

All values checked against vendor documentation on 2026-10-25, with the corrections from the independent checks applied. "unverified" means the official docs do not state it, or contradict themselves.
