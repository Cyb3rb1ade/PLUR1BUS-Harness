# D5 — user documentation: quickstart and operations handbook

**Goal.** `docs/user/{en,de}/quickstart.md` and `operations.md`, every command and path backed by the code, plus
`scripts/check-docs-commands.mjs` that checks the docs' `plur1bus ...` commands against `docs/cli.md`.

**Approach.** Facts come from `crates/plur1bus/src/paths.rs` (layout), `service/` (names, files), `output.rs` (exit
codes), `docs/rpc.md` (error codes), a built binary's `--help` and a scratch-home run of `1staid check`.
Script: parse `docs/cli.md` headings (commands) and `* \`--flag\`` lines (options per command); extract commands
from fenced lines and inline spans; unit-tested in `scripts/check-docs-commands.test.mjs`; wired into
`pnpm docs:check`; DE and EN must quote the same command set.

**Rulings.** This build has no `chat`, `backup` or applying `update`: the pages say so and give the real
alternative (`memory add/recall`, copy of the stopped home, `update --check` + `setup`). Nothing is called "planned"
except the one sentence the binary itself prints (`update` arrives in M8).
