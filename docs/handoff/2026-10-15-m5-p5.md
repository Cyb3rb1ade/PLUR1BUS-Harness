# M5 phase 5 — Private chat promotion and acceptance package

Builds on #516, #515, #514, #510 and M3 P1 #493 (normal merge, still open).

## Inventory / decisions / behavior

ChatPromotion adds owned preview/commit/private-link retrieval. Omitted choice
means no content. Summary, selected IDs and full transcript are explicit; system
messages are excluded. Preview is RAM-only, person/source/destination-bound,
expires after ten minutes and refuses stale content. Commit accepts only preview
id, rechecks rights and is idempotent after success. Original chat owner, agent,
kind, scope and messages do not change. No source id/title is placed on the board.
Private links are filtered by current project visibility and visible only to the
source owner. Incognito preview does not persist private content before choice.

Web chat menu has DE/EN destination/content choice, exact preview, confirmation,
focus handling and selected-message controls. Choosing a different option clears
the confirmation-ready preview. Destination navigation and prior private project
links are available in the dialog. Content limit: 64 KiB; full transcript refuses
more than 10,000 messages instead of silently truncating it.

Final integration pins kind/scope/authority/budget/return constraints across sender
repair, allows one malformed-return repair by the same target, preserves Unicode
bounds/artifact references, transfers acknowledged card ownership, carries actual
local/external/A2A target kind, and follows the live broker secret set for trace
redaction. Durable fan-out from incognito chats is refused to preserve M3 privacy.
