# M5 phase 3 — Replayable delegation sessions and trace UI

Builds on #514 (which builds on #510).

## Inventory / decisions / behavior

Additive collab migration binds span.sessionId. CollabOptions.sessions consumes
existing SessionStore APIs; production uses the already-owned store. Each hop
gets a project session with opaque project owner and no memory recall/capture.
Redacted contract/ack/result/usage provenance events plus transcript survive
restart. collab.session.replay checks current project visibility and the exact
persisted project/session binding. Workspace schema/fixtures/docs are generated.
Trace UI uses nested lists/details, duration/cost/tokens and keyboard transcript
links; DE/EN, escaped content, no inline style. Unknown cost remains unknown.
Known routed monetary costs include model settlements; local ack usage is added
to the work request's usage when reported. No mirroring is enabled.

Integration also closes the cross-project turn-counter gap: the tool closure
keeps total/pair counters in addition to per-project library traces. Collaboration
shuts down before its shared SessionStore.
