# M4 phase 2 — Matrix safety and experimental WASM crypto (blocked Draft)

Builds on #499. Persistent E2EE remains blocked after the owner-authorized bounded Node/SQLite spike.

## Inventar

- Exact matrix-sdk-crypto-wasm 18.9.0, one portable WASM package, no NAPI or other native package.
- Version-2 sync state with migration, durable pre-handler claims, encryption knowledge, 0600/Windows ACL,
  fsync+atomic replacement, serialization of cursor/safety writes.
- Encryption-state lookup after restart, recognition of timeline state transitions, plaintext refusal,
  fail-closed capacity limit, cursor parking when state or persistence is unknown.
- Opt-in memory-only Olm/Megolm send/receive and owner/admin SAS RPC + DE/EN Switchboard panel.
- Spike report docs/spikes/2026-10-15-matrix-crypto-storage.md and real-WASM/storage/crash regressions.

## Entscheidungen

The exact WASM API cannot accept the existing SQLite connection as a CryptoStore. Implementing correct
IndexedDB transaction/event/index semantics is beyond the one-day spike. No extra package added.
Fallback authorized by owner: memory crypto defaults off and warns that restart loses keys and verification.
Default device policy is reject; explicit allow is experimental. Cross-signing bootstrap and key backup
remain unavailable, never automatically trusted/uploaded. Persistent criterion 5 remains open.

Claims are persisted before handlers: **at most once**, not exactly once. Crash after claim and before
execution can lose a message. Preserve every uncommitted claim, then prune after cursor commit.
At encryption-state capacity, park the cursor; never forget a room's prior encrypted state.

## Verhaltensänderungen

Plaintext in encrypted rooms is refused even after restart. Unknown encryption state or failed durable
claims stop cursor advancement. Legacy cursors migrate without silently discarding them. Normal mode
still refuses encrypted rooms. Experimental memory crypto may be selected explicitly; every restart
requires new trust. No persistent crypto, recovery backup or cross-signing acceptance claim.
