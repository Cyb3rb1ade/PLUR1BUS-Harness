## Inventory and decisions

- `scripts/check-toolchain.mjs` invokes Windows pnpm through fixed explicit cmd.exe arguments, preserving version floors and returning a bounded failure. A .cmd cannot be executed directly by execFileSync; changing only its suffix would not fix the issue. Unix uses direct execution. Injectable tests cover both plans; the real Windows shim test runs only on Windows. macOS /var→/private/var module entry-point detection is fixed as well.
- `apps/desktop/scripts/ui-browser.mjs` resolves the exact UI Playwright 1.63.0 dependency and bundled browser metadata, installs through that package CLI, launches its headless Chromium and verifies the actual version. One explicit absolute PLAYWRIGHT_BROWSERS_PATH must be shared by install and tests. No system Chrome or mismatched cache fallback; no assertions skipped. Existing fixture profiles/ports remain isolated.
- Existing desktop CI retains all prior runtime/native/fixture tests and advisory reproducibility. Added packaging/probe/tooling tests and native singleton link test are bounded. New native bundle preview matrix covers macOS arm64, Windows x64/arm64 and Linux x64/arm64, beta/stable channels, online/offline direct variants and online Store/Flatpak plans. Artifacts and provenance are preserved between variant builds; unsigned/ad-hoc is explicit. Native availability, Store identity and Flatpak ABI/tooling remain acceptance conditions.
- [`docs/demos/d1.md`](../../demos/d1.md) is the owner worksheet: five-target installs with/without runtime, pairing, SPA, update/rollback, migration interruption, all uninstall levels, spoken readers, keyboard/zoom/theme/locales. It deliberately starts NOT RUN/BLOCKED. `docs/milestones.md` Track D separates draft implementation, local tests, known gaps and native acceptance. No milestone criteria or estimates changed.

## Threats and behavior

| Failure/attack | Protection | Evidence |
|---|---|---|
| Batch shim fails direct process launch | Fixed Windows cmd.exe command, no interpolated command/input | Injected plan + real Windows-only pnpm.cmd fixture |
| Hostile tool/version process | Known-tool enum, 10s/64KiB limits, fixed argv | Timeout/failure tests; version floors unchanged |
| Browser cache/package mismatch | Exact package version/revision metadata; fresh shared storage; launch version verified | Pinned-browser tests and isolated actual install/launch |
| Variant build overwrites evidence | Per-target/channel/variant artifact capture and payload provenance | Staging tests and workflow/source review |
| PR credential exfiltration/publication | Read-only workflow permissions, no signing secrets, SHA-pinned actions, no publication | Static workflow review |
| Mock/preview labelled real acceptance | Explicit fixture flags and worksheet/result taxonomy | Native report fullDesktopApiGate=false; manual rows unrun |
