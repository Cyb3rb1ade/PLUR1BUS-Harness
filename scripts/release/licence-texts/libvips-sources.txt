Prebuilt libvips binaries: where their source is

The npm packages @img/sharp-libvips-<platform> contain prebuilt shared libraries of libvips and of the
libraries it uses. The packages @img/sharp-win32-<arch> contain the same libraries for Windows, next to
sharp's own binding.

- @img/sharp-libvips-<platform> version X.Y.Z is published from the release tag vX.Y.Z of
  https://github.com/lovell/sharp-libvips, whose build scripts compile the upstream sources.
- @img/sharp-win32-<arch> version X.Y.Z is published from the release tag vX.Y.Z of
  https://github.com/lovell/sharp.
- In each of these packages, versions.json names the exact upstream version of every bundled library,
  and README.md names the licence each library is used under.
