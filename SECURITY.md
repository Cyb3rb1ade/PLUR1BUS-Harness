# Security Policy

## Supported versions

This project has not published a stable release yet. Until the first stable release, the current
default branch is the only version considered for security fixes. After a stable release, security
fixes will be made for the latest stable release; older releases and development snapshots are
not supported.

## Reporting a vulnerability

Please report suspected vulnerabilities privately through
[GitHub Security Advisories](https://github.com/Cyb3rb1ade/PLUR1BUS-Harness/security/advisories/new)
using **Report a vulnerability**. Do not report security issues in public issues, discussions,
or pull requests.

Include the affected version or commit, a description of the impact, and steps or a proof of
concept sufficient to reproduce the issue. Please avoid sharing real user data or secrets.

## Scope

Reports are in scope when they identify a vulnerability in this repository's maintained code,
its release artifacts, or a dependency as used by the project, and demonstrate a realistic
security impact.

The following are generally out of scope:

- Vulnerabilities affecting only unsupported versions or development snapshots.
- Issues in upstream projects that do not create a security impact in this project.
- Findings based only on missing hardening or best-practice recommendations, without a
  demonstrated vulnerability.
- Social engineering, physical attacks, and denial-of-service reports that require unusually
  large or otherwise unreasonable resources.

## Response

We intend to acknowledge reports within five business days and provide an initial assessment
within ten business days. These are goals, not guarantees; response and remediation times may
vary depending on the report and maintainer availability. Please keep details private while a
report is being investigated and coordinated.
